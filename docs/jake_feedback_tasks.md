# Jake's Website – Feedback & Tasks

> Feedback received for the website design. Organized by platform and section, with checkboxes for tracking. Reviewer's reasoning is included where it helps explain the "why".

---

## 🖥️ Desktop

### General Layout & Spacing

- [x] **Reduce vertical spacing** in most sections (top and bottom padding is too large right now).
- [x] **Fit each section on one screen** — user shouldn't need to scroll to see a full section. Applies especially to the image/content section, the reviews section, and any section where the right-side picture forces extra scroll.

### Colors / Blocks

- [ ] The yellow blocks feel flat and a bit boring. Replace with a **richer "goldish yellow"** for better contrast.

### Packages Section (biggest block of feedback)

- [x] **Rename / restructure the "1-on-1" vs "1-on-1 with Jake" packages.**
  Reviewer's concern: if the difference is "Jake vs other teachers", that implies the other teachers are worse, which is bad for marketing and not scalable. Find a different way to differentiate them.
- [x] **Show number of hours** in each package. The main differentiator besides name should be hours + price.
- [x] **Develop the package description a bit more** — currently too thin.
- [x] **Show the key difference between packages directly on the card** (at first glance, with minimal detail), so the user understands the difference without clicking.
- [x] **Active/selected state** — right now the first package is black by default. Make it so that clicking another package turns *that* one black (or use a selected-state style like the screenshot reference he sent). User should always know which package is currently selected.
- [x] **Reconsider mentioning the "pathway"** — if group classes are more profitable than 1-on-1, lean into groups and don't highlight the pathway. (Reviewer's note: "More moneyyyy.")

### Icons / Pictos

- [x] **Replace the current pictos** — they are too minimalist and hurt the visual richness of the page. Flat design is fine, but not *this* flat.

### Images

- [x] **Cap image height to the section height** — right-side images should never be taller than the section they're in.
- [ ] Reduce surrounding spacing so the whole section (image + content) fits in one screen view.

### Reviews Section

- [x] **Add a slider/carousel** so users can browse more reviews without going to a dedicated reviews page.
- [ ] Ensure the entire reviews section fits in one screen (no scroll inside the section).

### Typography (readability)

- [ ] One text block is **hard to read, especially for older parents**. Restyle it to match the header block at the top of the page (same font treatment/weight/color).

### Contact Form

- [x] **Form is too wide.** Move the left-side content **above** the form, and let the form span full width. This reduces scrolling.
- [x] **Duplicate "Name" field** — remove one.
- [x] **Age field** — change from dropdown list to a **free text input**. Reasoning: don't want to exclude a 20-year-old who wants to sign up. A customer is a customer, even if kids are the main target.

### Footer

- [ ] Not reviewed yet — reviewer skipped this as it looked unfinished.

### ❓ Open Question

- [ ] **Day abbreviations (Mon, Tue, Wed…)** — will all parents understand these, or should they be written in full? Decide based on your audience. — **OPEN: awaiting decision.**
