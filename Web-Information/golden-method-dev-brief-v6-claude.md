## Global Rules

1. **No pricing on homepage** — pricing lives inside program modal pages only
2. **No instant booking** — form submits an enquiry only, manual follow-up by consultant
3. **No "lesson"** → session
4. **No "class / classes"** → program / group
5. **No "teaching" / "taught"** → coaching / guided / worked with
6. **No "teacher"** → consultant / coach
7. **No "tutor" / "tutoring"** → consultant / consulting
8. **No "child" / "children" / "kids"** → students / young learners (case by case)
9. **No "classroom"** → session
10. **No "drilling" / "drills"** → remove entirely
11. **No "exercise"** → practice
12. **No "education"** → reframe around outcomes
13. **No "learning"** → progress / growth
14. **No age ranges on program cards** — personalised to level, not age
15. **"Students"** — general/stat references. Avoid possessive "your student"
16. **UI clean, premium, minimal** — no clutter, no discount language
17. **About section** — Jake's first person "I/my". All other sections use "we"
18. **Short sentences** — max 1 sentence per card body, max 2 per section body
19. **Simple words** — written for non-native English readers, easy to translate to Chinese
