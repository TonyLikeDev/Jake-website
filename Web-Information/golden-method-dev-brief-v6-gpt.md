# The Golden Method — Website Language & UX Refinements

## 🎯 Core Direction
This is not a tutoring website.

Positioning:
- Language consulting
- Expression-first system
- Premium, structured, intentional

Avoid sounding like:
- Tutoring platforms
- Schools
- Casual lesson marketplaces

---

## 🔘 CTA RULE (IMPORTANT)
All trial-related buttons must use EXACT wording:

**Request a Trial**

Do NOT use:
- Book a Trial
- Start Now
- Free Trial
- Trial Appointment

This keeps the tone simple, clean, and consistent.

---

## 🧠 LANGUAGE SYSTEM (GLOBAL RULES)

### ❌ Avoid These Words
- lesson / lessons
- class / classes
- student / students
- child / children
- kid / kids
- classroom
- education / educational

### ✅ Preferred Alternatives
- session / sessions
- people / individual
- communication
- expression
- guidance
- development
- progress

⚠️ Do not overuse “learner” — use natural phrasing where possible.
